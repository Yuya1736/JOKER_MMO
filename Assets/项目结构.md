# Joker MMO 项目代码架构

## 一、项目整体架构

**热更新方案**: 使用 **HybridCLR** 热更新技术
- AOT代码（不能被热更新）位于 `AOT` 目录
- 可热更新的代码位于 `HotUpdate` 目录
- 通过 `HotUpdateSystem.cs` 加载热更新DLL和AOT元数据补充

**网络架构**: 使用 **Unity Netcode for GameObjects** 网络框架
- 传输层: Unity Transport Protocol (UTP)
- 支持客户端/服务器双模式运行
- 消息协议使用 `INetworkSerializable` 接口自定义

## 四、模块划分

### 1. 网络模块 (Network)
- **核心**: `NetManager` 扩展 `NetworkManager`
- **消息协议**: `NetMessage.cs` 定义所有消息类型和结构
- **传输**: Unity Transport Protocol (UTP)
- **消息类型**: 注册/登录/进入游戏/断开连接/聊天/获取背包数据/使用物品

### 2. AOI模块 (Area of Interest)
- **核心**: `AOIManager` 单例
- **机制**: 基于区块(chunk)的可见性管理
- **功能**: 
  - 客户端区块同步
  - 服务器对象可见性控制
  - 优化大范围多人在线性能

### 3. 物品系统 (Item System)
- **配置**: `ItemConfigBase` / `WeaponConfig` / `ConsumableConfig` / `MaterialConfig`
- **数据**: `BagData` / `ItemDataBase` / `WeaponData` / `ConsumableData` / `MaterialData`
- **操作**: 使用物品、添加物品、背包数据同步

### 4. UI系统 (UI System)
- **框架**: 基于 `JKFrame.UISystem`
- **窗口**: 登录/注册/主菜单/游戏弹窗/背包/聊天/加载
- **层级管理**: 支持多层级显示和输入阻断

### 5. 地图模块 (Map)
- **客户端**: `ClientMapManager` / `QuadTree`
- **服务器**: `ServerMapManager`
- **配置**: `MapConfig`

### 6. 客户端管理模块 (Server)
- `LoginSystem`: 登录验证
- `ChatSystem`: 聊天消息处理
- `ItemSystem`: 物品操作处理
- `ClientsManager`: 客户端连接管理
- `DataBaseManager`: MongoDB数据持久化

## 五、数据流说明

### 客户端启动流程
```
ClientLaunch (AOT入口)
    ↓
HotUpdateSystem.StartHotUpdate()
    ↓ [热更新成功]
ResSystem.InstantiateGameObject("ClientGlobal")
    ↓
ClientGlobal.Init() → 初始化网络、UI、场景
    ↓
加载 LoginScene → 登录/注册 → 加载 GameScene
    ↓
GameSceneManager 根据 NetManager.IsClient/IsServer
    实例化 ClientOnGameScene 或 ServerOnGameScene
```

### 网络通信流程
```
客户端发送消息 → NetMessageManager → Unity Netcode
    ↓
服务器接收 → Server端Handler处理 → 数据持久化
    ↓
服务器发送响应 → 客户端接收更新 → UI/数据更新
```

### AOI数据流
```
玩家移动 → 计算新区块坐标
    ↓
触发 UpdateClientAOIEvent
    ↓
AOIManager.UpdateClientVisualChunk()
    ↓
计算差异区块 → 显示/隐藏对应对象
    ↓
优化网络同步，只同步可见区域
```

## 六、技术栈总结

| 技术/框架 | 用途 |
|-----------|------|
| **Unity Netcode** | 多人网络游戏框架 |
| **Unity Transport (UTP)** | 网络传输层 |
| **HybridCLR** | C#热更新方案 |
| **Addressables** | 资源管理系统 |
| **JKFrame** | 第三方Unity开发框架（单例、事件、资源、UI等） |
| **MongoDB (Bson)** | 数据库持久化 |
| **Cinemachine** | 摄像机控制（FreeLook） |
| **Localization System** | 多语言本地化 |

---

## 七、关键设计模式

1. **单例模式**: 大量使用 `SingletonMono<T>` (来自JKFrame)
2. **事件驱动**: 使用 `EventSystem` 解耦模块间通信
3. **状态机**: 玩家状态使用状态机管理
4. **AOT+HotUpdate分离**: 核心启动逻辑在AOT，业务逻辑在HotUpdate
